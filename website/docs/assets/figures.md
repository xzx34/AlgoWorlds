# Paper figure assets

`public/figures/algoworlds-figure-1.png` is a raster export of the paper artwork
using the current information-sufficiency terminology. It is pinned to one
reviewed paper build and must not be regenerated from a different PDF without
updating the inventory.

Export parameters:

- source PDF SHA-256: `1fff1553f1ee144c2adea438f9bcfcb77d87302c9d1fd41bae7f0d27618d105c`
- source: `main.pdf`, page 2
- PDF crop rectangle: `(59, 80, 534, 216)` points
- render scale: 6x
- image size: 2850 x 816 pixels
- image SHA-256: `2509ed1e2815a5c39224d8487f34d7e420b1424037ebef6664625bb77f9321d8`

The crop removes only the running header and the long paper caption. The
scientific artwork and all values inside it are unchanged. The AlgoWorlds
project lead approved redistribution for the official project page and source
release on 2026-08-28. The artwork remains excluded from the repository's
Apache-2.0 and CC BY 4.0 licenses; approval is recorded in `ASSETS.json` in this
directory.
