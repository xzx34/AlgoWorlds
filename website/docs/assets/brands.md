# Brand assets

`public/brands/weixin-mark.svg` is the green double-bubble mark shown beside
the visible `Weixin AI` organization name. It is decorative on the page; the
adjacent text provides the accessible label.

Third-party provider logos are intentionally not distributed. The leaderboard
uses neutral text badges to identify providers without republishing their
trademarks as image assets.

The AlgoWorlds project lead approved redistribution of the Weixin mark for the
official project page and source release on 2026-08-28. The mark remains
excluded from the repository's Apache-2.0 and CC BY 4.0 licenses. Checksums and
the release record are maintained in `ASSETS.json` in this directory.
